## 🚀 Deployment Steps

### Step 1: Push Your Code to GitHub

Your code is already in the repository. Make sure it's up to date:

```bash
git status
git add .
git commit -m "Prepare for cloud deployment"
git push origin claude/ai-video-automation-system-atkMj
```

### Step 2: Sign Up for Render.com

1. Go to https://render.com
2. Click **"Get Started"**
3. Sign up with GitHub (recommended)
4. Authorize Render to access your repositories

### Step 3: Create a New Web Service

1. From Render Dashboard, click **"New +"**
2. Select **"Web Service"**
3. Connect your GitHub repository:
   - Repository: `YouTube-automation-`
   - Branch: `claude/ai-video-automation-system-atkMj`

### Step 4: Configure the Service

Render will auto-detect the `render.yaml` file, but verify these settings:

**Basic Settings:**
- **Name:** `ai-content-automation-dashboard`
- **Region:** `Oregon (US West)` (or closest to you)
- **Branch:** `claude/ai-video-automation-system-atkMj`
- **Runtime:** `Python 3`
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `gunicorn -w 4 -b 0.0.0.0:$PORT --timeout 120 dashboard.app:app`

**Plan:**
- Select **"Free"** (0 cost, 750 hours/month)

### Step 5: Add Environment Variables

In the Render dashboard, add these environment variables:

**Required API Keys:**
```
ANTHROPIC_API_KEY = sk-ant-your-key-here
OPENAI_API_KEY = sk-your-key-here
REPLICATE_API_TOKEN = r8-your-token-here
ELEVENLABS_API_KEY = your-key-here
```

**Optional:**
```
RUNWAY_API_KEY = your-runway-key (if using Runway)
SECRET_KEY = (auto-generated by Render)
FLASK_ENV = production
```

**How to add:**
1. Scroll to **"Environment"** section
2. Click **"Add Environment Variable"**
3. Enter key and value
4. Click **"Save"**

### Step 6: Add Persistent Disk (Important!)

This ensures your SQLite database persists across deploys:

1. Scroll to **"Disk"** section
2. Click **"Add Disk"**
3. Configure:
   - **Name:** `data`
   - **Mount Path:** `/opt/render/project/src/data`
   - **Size:** `1 GB` (free tier)
4. Click **"Save"**

### Step 7: Deploy!

1. Review all settings
2. Click **"Create Web Service"**
3. Render will:
   - Clone your repo
   - Install dependencies
   - Start the dashboard
   - Assign a public URL

**Deployment takes 3-5 minutes.**

### Step 8: Access Your Dashboard

Once deployed, Render provides a URL:

```
https://ai-content-automation-dashboard-xxxx.onrender.com
```

**That's your public dashboard!** 🎉

## 📊 Free Tier Limits

Render free tier includes:
- **Compute:** 750 hours/month (enough for 24/7)
- **Memory:** 512 MB RAM
- **Disk:** 1 GB persistent storage
- **Bandwidth:** Shared

**Note:** Free tier services spin down after 15 minutes of inactivity. First request after spin-down takes ~30 seconds.

### Prevent Spin-Down (Optional)

Use a free service like UptimeRobot to ping your dashboard every 10 minutes:
1. Sign up at https://uptimerobot.com
2. Add monitor with your Render URL
3. Set interval to 10 minutes

## 🐛 Troubleshooting

### Dashboard Won't Load

**Check Logs:**
1. Render dashboard → Logs tab
2. Look for errors in startup

**Common Issues:**
- Missing environment variables
- Wrong branch name
- Dependencies failed to install

**Solution:** Verify all environment variables are set.

### "Service Unavailable" (503)

**Cause:** Free tier spun down

**Solution:** Wait 30 seconds for spin-up, or set up UptimeRobot.

### Generation Fails

**Check:**
1. API keys are correct in environment variables
2. Budget caps allow generation
3. Logs for specific error messages

**Solution:** Verify API keys have sufficient credits.

### Database Resets

**Cause:** Disk not configured

**Solution:** Add persistent disk in Render settings (see Step 6).

### Out of Memory

**Symptom:** Crashes during generation

**Cause:** Free tier has 512MB RAM limit

**Solution:**
- Reduce `MAX_CONCURRENT_GENERATIONS` in config
- Upgrade to paid plan ($7/month for 1GB RAM)

## 💰 Cost Optimization

### Stay on Free Tier

1. **Single worker:** Use `-w 1` instead of `-w 4` in start command
2. **Reduce concurrency:** Lower parallel generations
3. **Optimize requests:** Cache when possible

### When to Upgrade

Consider paid plan ($7/month) if:
- Generating multiple videos per day
- Multiple active channels
- Need faster response times
- Want to prevent spin-down
